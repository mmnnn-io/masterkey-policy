Privacy Policy / プライバシーポリシー

日本語 English

最終更新日：2026年7月30日

1. はじめに

MasterKey（以下「本拡張機能」）は、Google スプレッドシートでのキーボードショートカット習得を支援するChrome拡張機能です。本プライバシーポリシーは、本拡張機能が収集・利用する情報について説明します。

2. 基本方針 — あなたのデータはデバイスから出ません

セルの内容・入力テキスト・個人を特定できる情報は一切デバイスの外に送信されません。外部との通信が発生するのは、次の2つの場合に限られます。
  • 匿名の利用統計 — 製品改善のため、操作回数などの匿名の数値を初期設定で送信します。設定画面からいつでもオフにできます（第4条）
  • Pro プランの決済とライセンス確認 — 有料プランをご利用の場合のみ発生します（第5条）

3. 収集する情報（デバイス内に保存）

本拡張機能は、以下の情報をお客様のデバイス上にローカルに記録します。

  • Google スプレッドシート上での操作の種別と回数（マウス操作・キーボードショートカット使用）
  • 各ショートカット操作の日付別の使用回数
  • ポップアップ表示位置などの設定情報

本拡張機能は、セルの内容・入力テキスト・個人を特定できる情報は一切収集しません。

4. 匿名の利用統計（初期設定で有効・任意でオフ）

本拡張機能の改善のため、最小限の匿名の統計データを当方が運用するサーバー（Cloudflare 上でホスト）に初期設定で送信します。送信されるのは操作回数などの数値のみで、あなたを特定することはできません。

いつでもオフにできます

  • オンボーディング画面、または設定画面からいつでもオフにできます
  • オフにすると、それ以降は統計データを1バイトも送信しません

送信される情報

  • ランダムに生成された識別子（UUID。Googleアカウント等とは無関係）
  • 拡張機能のバージョン・OS種別・表示言語
  • インストールからの経過日数
  • 操作回数の日次集計値（マウス操作数／キーボードショートカット使用数／ポップアップ表示回数／サイドパネルを開いた回数／習得済みショートカット数／検知エラー数）
  • ショートカット別の操作回数内訳（前日のショートカットIDごとのマウス操作数・キーボード操作数の匿名カウント）
  • 未検出クリックのシグネチャ（クリック種別・要素ID・aria-label・メニューの経路を結合した匿名識別子。メニューの経路とは「どのメニュー（ファイル／データ等）を開いた何段目か」という画面構造の情報で、クリックしたメニュー文言は含みません）
  • 設定変更・ミュート操作（ポップアップON/OFFや表示位置などの設定変更、ショートカットのミュートのON/OFFを匿名カウント）
  • 初回ポップアップ表示・サイドパネル初回表示・同意設定の変更、といった節目のイベント
  • 1日1回の稼働確認（v0.2.8以降）— 本拡張機能が有効なままかどうかを把握するため、スプレッドシートを開いていない日も1日1回だけ、次の情報を送信します：最後にスプレッドシートを開いてからの日数、最後に統計を送信してからの日数、ポップアップ表示のON/OFF、スプレッドシートへのアクセス許可の有無。日付や時刻、閲覧していたページ、操作内容は含みません（送信する日数は、たとえば「3日前」のような粒度の数値です）。統計をオフにしている場合は送信しません

設定にかかわらず、決して送信しない情報

  • セルの内容・入力テキスト
  • スプレッドシートのURL・タイトル
  • クリックしたメニューの文言などの画面上のテキスト
  • Googleアカウント情報・氏名・メールアドレス
  • IPアドレス（サーバー側でも保存しません）

サードパーティの分析サービス（Google Analytics 等）は使用しません。送信されたデータは匿名であり、特定の個人と紐付けることはできません。

5. Pro プランの決済とライセンス確認

有料の Pro プランの決済は、Chrome拡張向け決済サービス ExtensionPay（extensionpay.com）および決済代行サービス Stripe を通じて行われます。

  • クレジットカード情報は Stripe が直接処理し、本拡張機能がカード情報を受け取ることはありません
  • 本拡張機能は、Pro プランの有効状態を確認するために extensionpay.com と通信します。この通信にスプレッドシートの内容や操作データが含まれることはありません
  • 決済時に登録するメールアドレスは ExtensionPay / Stripe が管理し、本拡張機能のサーバーには保存されません
  • Pro をご購入・トライアルを開始された場合、サポートと製品改善のため、匿名の利用ID（clientId）をご契約（ExtensionPay）に関連付けます。この関連付けは匿名利用統計とは別に保存し、メールアドレスやカード情報を当社サーバーに保存することはありません
  • トライアルの開始・Pro のご利用に伴い、匿名の利用統計が有効になります（設定画面からいつでも確認できます。第4条）

詳細は ExtensionPay のプライバシーポリシーおよび Stripe のプライバシーポリシーをご参照ください。

6. 情報の利用目的

収集した情報は、以下の目的にのみ使用します。

  • ショートカットキーの習得支援および拡張機能の機能提供（ローカルデータ）
  • 機能改善・品質向上のための統計分析（匿名統計のみ）
  • Pro プランのライセンス管理（決済関連情報のみ）

収集したデータをマーケティングや広告に利用すること、第三者に販売することはありません。

7. 情報の保存と管理

  • 利用データは Chrome のローカルストレージ（chrome.storage.local） に保存されます
  • 一定期間を経過した古いデータは、拡張機能の起動時に自動的にクリーンアップされます
  • 拡張機能をアンインストールすると、デバイス上のすべてのデータが削除されます
  • 送信された匿名統計は、改善分析に必要な期間のみ保持します。匿名のため特定のお客様のデータを遡って特定することはできませんが、削除のご要望は第12条の窓口で受け付けます

8. 第三者への提供

本拡張機能は収集したデータを第三者に販売・共有することはありません。サービス提供のため、以下の事業者をデータ処理に利用します。

  • Cloudflare — 匿名利用統計の収集サーバーのホスティング（オフにしていない場合）
  • ExtensionPay / Stripe — Pro プランの決済処理（購入時のみ）

9. お客様の権利と選択

  • 匿名利用統計の送信は、設定画面からいつでも停止できます
  • Chrome の拡張機能管理ページからいつでも本拡張機能をアンインストールでき、その際デバイス上のすべてのデータが削除されます
  • Pro 契約に関連付けられた匿名利用IDの関連付けデータも、第12条の窓口を通じて削除をご請求いただけます

10. 対象ページ

本拡張機能は https://docs.google.com/spreadsheets/* のURLパターンに一致するページにのみ動作します。その他のWebサイトでは一切動作しません（Pro プランのライセンス確認のための extensionpay.com との通信を除く）。

11. 本ポリシーの変更

本ポリシーを変更する場合は、本ページを更新し、最終更新日を改定します。収集する情報の種類が増えるなど重要な変更を行う場合は、拡張機能内でお知らせします。

12. お問い合わせ

本ポリシーに関するご質問は、Chrome Web Store のサポートページよりお問い合わせください。

1. Introduction

MasterKey is a Chrome extension that helps you learn Google Sheets keyboard shortcuts. This Privacy Policy explains what information the extension collects and how it is used.

2. Our Principle — Your Data Stays on Your Device

Your cell contents, typed text, and any personally identifiable information never leave your device. External communication happens only in the following two cases:
  • Anonymous usage statistics — to improve the product, anonymous counts are sent by default. You can turn this off at any time in the settings (Section 4)
  • Pro plan payment and license verification — occurs only if you use the paid plan (Section 5)

3. Information Stored on Your Device

The extension records the following information locally on your device:

  • Action type and count — whether each Sheets operation was performed via mouse or keyboard shortcut
  • Daily usage counts per shortcut action
  • User preferences such as popup display position

The extension does not collect cell contents, typed text, or any personally identifiable information.

4. Anonymous Usage Statistics (On by Default, Optional)

To improve the extension, we send a minimal set of anonymous statistics to a server we operate (hosted on Cloudflare) by default. Only counts are sent, and they cannot be used to identify you.

You can turn it off anytime

  • You can turn it off at any time from the onboarding screen or the settings
  • Once off, not a single byte of statistics is transmitted from then on

What is sent

  • A randomly generated identifier (UUID, unrelated to your Google account)
  • Extension version, OS type, and display language
  • Days since installation
  • Daily aggregate counts of activity (mouse actions / keyboard shortcut uses / popup displays / side panel opens / mastered shortcuts / detection misses)
  • Per-shortcut action counts — anonymous counts of mouse and keyboard actions per shortcut ID for the previous day
  • Undetected-click signatures — an anonymous identifier composed of click type, element ID, aria-label, and the menu route. The menu route is UI-structure information only: which menu (File, Data, …) was open and how many levels deep the click was. The menu text you clicked is never included.
  • Setting changes and mute actions — anonymous counts of setting changes (e.g. popup on/off, position) and shortcut mute toggles
  • Milestone events such as first popup shown, first side panel open, and consent changes

What is never sent, regardless of this setting

  • Cell contents or typed text
  • Spreadsheet URLs or titles
  • On-screen text such as the labels of menus you click
  • Google account information, your name, or email address
  • IP addresses (not stored on the server either)

We do not use third-party analytics services (such as Google Analytics). The data sent is anonymous and cannot be linked back to any individual.

5. Pro Plan Payment and License Verification

Payments for the paid Pro plan are processed through ExtensionPay (extensionpay.com), a payment service for Chrome extensions, and the payment processor Stripe.

  • Credit card details are handled directly by Stripe — the extension never receives your card information
  • The extension communicates with extensionpay.com to verify your Pro plan status. This communication never includes spreadsheet contents or your activity data
  • The email address you register at checkout is managed by ExtensionPay / Stripe and is not stored on our servers
  • If you purchase Pro or start a free trial, we associate your anonymous usage ID (clientId) with your contract (ExtensionPay) for support and product improvement. This association is stored separately from the anonymous usage statistics, and your email address and card information are never stored on our servers
  • Starting a trial or using Pro enables anonymous usage statistics (you can review this anytime in Settings — see Section 4)

For details, see the ExtensionPay Privacy Policy and the Stripe Privacy Policy.

6. How We Use the Information

Collected data is used solely for the following purposes:

  • Providing the extension's functionality and helping you learn keyboard shortcuts (local data)
  • Statistical analysis to improve the product (anonymous statistics only)
  • Pro plan license management (payment-related information only)

We do not use your data for marketing or advertising, and we never sell it to third parties.

7. Data Storage and Retention

  • Usage data is stored in Chrome local storage (chrome.storage.local) on your device
  • Old data beyond the retention period is automatically cleaned up each time the extension runs
  • Uninstalling the extension removes all data stored on your device
  • Anonymous statistics that are sent are retained only as long as needed for product analysis. Because the data is anonymous, we cannot identify a specific user's records retroactively, but deletion requests are accepted via the contact channel in Section 12

8. Third-Party Sharing

We do not sell or share collected data with third parties. We use the following service providers to operate the product:

  • Cloudflare — hosting for the anonymous statistics collection server (unless turned off)
  • ExtensionPay / Stripe — payment processing for the Pro plan (at purchase only)

9. Your Rights and Choices

  • You can stop sending anonymous usage statistics at any time from the settings
  • You may uninstall the extension at any time from Chrome's extension management page; all data on your device will be removed
  • The association data linking your anonymous usage ID to a Pro contract can also be deleted on request via the contact channel in Section 12

10. Scope

This extension operates exclusively on pages matching https://docs.google.com/spreadsheets/*. It does not run on any other website (apart from communication with extensionpay.com for Pro license verification).

11. Changes to This Policy

When we change this policy, we will update this page and revise the "Last updated" date. For material changes — such as collecting new categories of data — we will notify you within the extension.

12. Contact

For questions about this policy, please contact us via the Chrome Web Store support page.
