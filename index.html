Privacy Policy / プライバシーポリシー

日本語 English

最終更新日：2025年5月28日

1. はじめに

MasterKey（以下「本拡張機能」）は、Google スプレッドシートでのキーボードショートカット習得を支援するChrome拡張機能です。本プライバシーポリシーは、本拡張機能が収集・利用する情報について説明します。

2. 収集する情報

本拡張機能は、以下の情報をお客様のデバイス上にローカルに記録します。

  • Google スプレッドシート上での操作の種別と回数（マウス操作・キーボードショートカット使用）
  • 各ショートカット操作の日付別の使用回数
  • ポップアップ表示位置などの設定情報

本拡張機能は、セルの内容・入力テキスト・個人を特定できる情報は一切収集しません。

3. 情報の利用目的

収集した情報は以下の目的のみに使用します。

  • 週次サマリーの表示（総操作数・キーボード率・削減時間の計算）
  • ショートカットの習得状況の判定・表示
  • 次に覚えるべきショートカットの推薦

4. 情報の保存と管理

  • すべてのデータは Chrome のローカルストレージ（chrome.storage.local） に保存されます
  • データは外部サーバーに送信されることは一切ありません
  • データは自動的に 90日後に削除されます
  • 拡張機能をアンインストールすると、すべてのデータが削除されます

5. 第三者への提供

本拡張機能は収集したデータを第三者に提供・販売・共有することはありません。

6. お客様の権利

Chrome の拡張機能管理ページからいつでも本拡張機能をアンインストールでき、その際すべてのデータが削除されます。

7. 対象ページ

本拡張機能は https://docs.google.com/spreadsheets/* のURLパターンに一致するページにのみ動作します。その他のWebサイトでは一切動作しません。

8. お問い合わせ

本ポリシーに関するご質問は、Chrome Web Store のサポートページよりお問い合わせください。

日本語 English

Last updated: May 28, 2025

1. Introduction

MasterKey is a Chrome extension that helps you learn Google Sheets keyboard shortcuts. This Privacy Policy explains what information the extension collects and how it is used.

2. Information We Collect

The extension records the following information locally on your device only:

  • Action type and count — whether each Sheets operation was performed via mouse or keyboard shortcut
  • Daily usage counts per shortcut action
  • User preferences such as popup display position

The extension does not collect cell contents, typed text, or any personally identifiable information.

3. How We Use the Information

Collected data is used solely to:

  • Display your weekly summary (total actions, keyboard rate, estimated time saved)
  • Determine and display your shortcut mastery status
  • Recommend which shortcuts to learn next

4. Data Storage and Retention

  • All data is stored in Chrome local storage (chrome.storage.local) on your device
  • Data is never transmitted to any external server
  • Data is automatically deleted after 90 days
  • Uninstalling the extension removes all stored data

5. Third-Party Sharing

We do not sell, share, or disclose collected data to any third parties.

6. Your Rights

You may uninstall the extension at any time from Chrome's extension management page. All data will be removed upon uninstallation.

7. Scope

This extension operates exclusively on pages matching https://docs.google.com/spreadsheets/*. It does not run on any other website.

8. Contact

For questions about this policy, please contact us via the Chrome Web Store support page.
